## 📌 About
This repository contains the source code for my personal portfolio website. Built with HTML5, CSS3, and JavaScript, featuring clean sub-pages for each project, interactive modal forms, and a neon dark mode aesthetic.

---

## ✨ Functionalities
- **Fully Responsive** layout optimized for desktop, tablet, and mobile devices.
- **Multi-Page Architecture** with dedicated interactive detail pages for individual projects.
- **Glassmorphism & Neon Design** styling with smooth scrolling and animated marquee skills tracker.
- **Interactive Contact/Question Modal** built with vanilla JavaScript.
